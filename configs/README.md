# 实验配置

此目录保存公开JSON配置，不保存凭据。`base.json`提供公共参数，`smoke.json`继承并运行24组离线矩阵；`chat.example.json`仅供手动配置接口连通性测试。

配置至少记录：事件与划分、主轴与测量范围、模型/接口标识、prompt哈希、采样设置、记忆策略、网络和访问参数、同步提交规则、种子、候选动力学、主指标、预算与输出run_id。

凭据使用环境变量或被忽略的本地文件，不进入冻结配置。修改配置使用新版本，不覆写已运行批次。

路径相对于定义字段的配置文件解析。启动时合并配置，拒绝未知字段和非法值；输入、prompt、协议或源码变化生成新run_id。当前以JSON实现以避免增加依赖，后续如引入YAML须保留相同的校验与冻结语义。具体命令、字段和限制见 [运行说明](../docs/RUNNING.md)。
