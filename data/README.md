# 数据约定

新工程默认通过只读索引复用父项目数据，不批量复制历史数据、账号资料或旧响应。

待定义的索引包括原始文件路径/哈希、事件与时间范围、来源版本、轨迹与评分来源、划分用途和使用边界。派生数据与原始数据分开；不可把缺失响应填成有效null，也不可把模拟fixture当作实际模型输出。

当前已有 `fixtures/scenarios.json`（显式虚构场景，仅作工程测试）与 `legacy_sources.json`（迁移函数来源与哈希）。已提供schema_version=1的逐轮记录及E23只读适配；E23派生审计数据放在outputs新目录，保留原文、来源、行号、历史测量范围与未校准标记。未复制原始大规模输入、模型权重或凭据。正式研究的测量schema与划分仍需P0/P1冻结。
